# 🤖 Virtual Assistant

A smart AI-based Virtual Assistant made using HTML, CSS, and JavaScript.

## 🚀 Features

* Voice Recognition
* Speech Response
* Modern UI Design
* Responsive Layout
* User-Friendly Interface
* Real-time Interaction

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Web Speech API

## 📂 Project Structure

```bash
VIRTUAL-ASSISTANT/
│── index.html
│── style.css
│── script.js
│── images/
```

## 🎯 Purpose of Project

This project was created to practice frontend development and JavaScript voice assistant functionality.
